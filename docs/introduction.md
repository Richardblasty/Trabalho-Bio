# Introdução

## Visão geral

Esta seção apresenta o contexto geral do projeto e os principais conceitos
necessários para compreender seu desenvolvimento.

## Objetivos

O objetivo deste projeto é desenvolver uma solução organizada, documentada
e versionada.

### Objetivos específicos

- Definir os requisitos do projeto;
- Descrever a metodologia utilizada;
- Apresentar os resultados;
- Analisar os resultados obtidos;
- Registrar as referências utilizadas.
