    Overview

    Project Overview

    The CpHMD / MM/PBSA suite aims to standardize protonation analysis and binding free-energy calculations for the scFv m971 × CD22 antibody–antigen system.

    i Scientific Objective

    Provide a traceable workflow for protonation analysis, molecular simulation processing and free-energy validation.

    Research question

    The project records in its methodological decisions (RDM) its subject: the effect of pH on the antibody–antigen interface (scFv m971 ↔ CD22) studied by constant-pH molecular dynamics. In λ-dynamics, each titratable site is described by a continuous coordinate λ; the suite turns those λ series into protonation states and microstates, computes the binding free energy of each microstate with MM/PBSA and checks the integrity of the results before they are reported.

    Architecture

    System Architecture

    The system consists of three main products that connect protonation analysis, GROMACS processing and free-energy data validation.

    1. P1

      protonation-analysis

      Processes XVG files, classifies protonation states, applies hysteresis and extracts TRR microtrajectories.

      Inputs
      λ coordinate series (.xvg) and the CpHMD trajectory (.trr)
      Outputs
      Microstates and microtrajectories (sub_msN), and membrana.json when membrane support applies
      Read Product 1 →
    2. P2

      gromacs-pipeline

      Prepares GROMACS structures and trajectories and automates MM/PBSA calculations in HPC environments.

      Inputs
      P1 microtrajectories, membrana.json (optional) and gromacs-pipeline.cfg
      Outputs
      FINAL_RESULTS_MMPBSA.csv / .dat and the per-folder status passo6_status.txt
      Read Product 2 →
    3. P3

      dg-analysis

      Aggregates free-energy results and checks data integrity and provenance.

      Inputs
      Results and status files of Product 2; outputs of Product 1 (read only)
      Outputs
      Aggregated ΔG, contract checks C1–C10 and provenance tables (proveniencia_p2, parametros_membrana)
      Read Product 3 →

    Source of inputs and outputs: records RDC-027 and RDC-000. Products only read the outputs of the previous product; Product 3 does not modify coordinates.

    Product 1

    Protonation Analysis

    This module analyzes protonation states, hysteresis, histidine microstates and molecular trajectory segments.

    Protonation State Classification

    Concept
    State Lambda Criterion
    Protonated λ ≤ 0.2
    Transition Zone 0.2 < λ < 0.8
    Deprotonated λ ≥ 0.8

    ! Important

    Lambda values outside the interval [0, 1] are retained without clamping.

    Hysteresis and Microstates

    Concept

    Transition-zone frames are not discarded during microstate analysis. The effective state inherits the last confirmed physical state.

    state_raw
    used to analyze dynamics, fluctuations and time in the transition zone.
    Effective state
    used to define microstates and select frames for MM/PBSA.

    Decision record: RDM-003, which replaced the transition-zone policy of RDM-001.

    Histidine Tautomers

    Concept

    The HSPT group is evaluated cooperatively under the physical constraint Σλ ≈ 1. HSP, HSD and HSE retain distinct identities in microstate signatures.

    Product 2

    GROMACS Pipeline and MM/PBSA

    This module prepares molecular structures, processes trajectories and runs binding free-energy calculations in high-performance computing environments.

    Processing Workflow

    Procedure
    1. pdb2gmx generates the topology and structure files.
    2. grompp creates the simulation run input file.
    3. make_ndx configures receptor and ligand index groups.
    4. trjconv processes periodic boundary conditions using the documented whole → mol sequence, without centering. See RDC-022.
    5. gmx_MMPBSA calculates binding free energy using the configured implicit membrane parameters.

    HPC Configuration

    Procedure

    The gromacs-pipeline.cfg file supports configurable worker counts and OMP/MPI parameters. The pipeline can also use membrana.json generated by Product 1 when membrane support is applicable.

    i Execution note

    Use the configuration files and version-specific instructions from the project repository before running production calculations.

    Product 3

    ΔG Analysis and Validation

    This module aggregates free-energy results and verifies data integrity and provenance before a batch is accepted for reporting.

    Binding Free-Energy Relationship

    Concept
    ΔGbinding = Gcomplex − Greceptor − Gligand

    Data Integrity Contracts

    Validation
    Contracts Validation Scope
    C1–C5 Frame counts, temporal alignment, system identity, energy consistency and CSV/DAT agreement.
    C6 Consistency of Poisson–Boltzmann parameters across folders.
    C7–C8 Microstate signature validation and reconstruction from the corrected PDB.
    C9–C10 PBC processing provenance and consistency of software versions and membrane modes.

    C1–C8 check the internal consistency of each folder. C9 is applied per folder and blocks invalid results; C10 checks that the whole batch is homogeneous. Introduced in dg-analysis 1.3.0 — see RDC-027.
