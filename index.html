gmx_MMPBSA

A GROMACS tool for Molecular Mechanics Poisson-Boltzmann Surface Area calculations.

Get started Documentation
01

Introduction

gmx_MMPBSA is a tool designed to perform Molecular Mechanics Poisson-Boltzmann Surface Area calculations using GROMACS molecular dynamics trajectories.

The program provides an interface for analyzing molecular systems and estimating binding free energies.

02

Installation

The installation process requires a compatible environment and the necessary dependencies.

Terminal 
pip install gmx_MMPBSA
03

Getting started

After installation, the software can be configured according to the requirements of the molecular system.

Information

Consult the documentation before running your first calculation.
